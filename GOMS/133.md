# GOMS v3.0.6 서버 배포 CD 터짐

## 문제 상황

GOMS v3.0.6 릴리즈 PR merge를 하니 CD가 실패함

## 원인 파악

#122번 PR에서 Redis가 외부 포트에 열려 있는 것 `127.0.0.1`을 추갛;ㅐ 고친 후 릴리즈를 안함
그리고 #132에서 그라파나 잘못된 5XX에러 또한 4XX를 바꾼 후 릴리즈를 안함

-> 그라파나에서 한번 더 에러가 터졌고 원인 파악 중 릴리즈가 되지 않아 아직 Redis 설정이 반영 되지 않은 서버의 compose 파일을 보고 직접 수정을 함

-> compose 파일 충돌이 일어나서 #133를 메인에 머지하자 CD가 터짐

## 해결

서버에서 원래대로 돌리는 방법을 택함

- `git checkout -- docker-compose.yml` -> 서버에서 직접 고친 내용을 버리고 원래 상태로 되돌림
- 배포 workflow 재실행 -> `git pull`이 성공했고 재실행 함
- `docker compose up -d mariadb redis app` 새 compose 설정으로 Redis와 MariaDB를 다시 만듦
